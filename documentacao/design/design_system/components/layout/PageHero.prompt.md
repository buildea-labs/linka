# PageHero

The eyebrow → 40px display headline → 17px lead block that opens every content page
(Sobre Nós, Como medimos, App's, Privacidade & Termos).

```jsx
<PageHero
  eyebrow="Como medimos"
  title="Três fases, um servidor próximo, sem estimativas."
  lead="O teste roda inteiramente no navegador. Nenhuma etapa é simulada…" />
```

One h1 per page. Headline is a full sentence with a period — the product's voice.
