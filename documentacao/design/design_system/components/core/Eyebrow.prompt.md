# Eyebrow

Uppercase mono label — the system's only uppercase text. Extracted from the prototype, where the
same 4-line inline style was repeated 15+ times (page eyebrow, section marker, in-card label).

```jsx
<Eyebrow>Como medimos</Eyebrow>          {/* page eyebrow, above the h1 */}
<Eyebrow size="sm">Disponível agora</Eyebrow>
<Eyebrow tone="accent">Termos de uso</Eyebrow>   {/* document part change */}
```

Never sentence-case an eyebrow, never longer than ~3 words, never a full sentence.
