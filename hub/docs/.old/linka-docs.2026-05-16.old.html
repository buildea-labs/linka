Linka — Diagnóstico de Internet Doméstica

App nativo Android + PWA para medir velocidade, Wi-Fi, DNS e diagnóstico assistido por IA.

Versões Ativas

Plataforma Versão Status
Android v0.6.3 ✓ Ativo (16 módulos)
PWA v1.0.0 ✓ Ativo (React + Vite)

Stack Técnico

Android

  • Kotlin + Jetpack Compose
  • Material Design 3
  • MVVM + Coroutines
  • Room + WorkManager

PWA

  • React 18 + TypeScript
  • Vite + Tailwind CSS
  • Cloudflare Pages
  • LocalStorage + IndexedDB

Funcionalidades Principais

  • SpeedTest: Mede DL, UL, latência, jitter, perda de pacotes
  • Wi-Fi Scan: Analisa redes, força sinal, canais
  • DNS Benchmark: Testa resolvedores
  • Diagnóstico IA (Orbit): Chat inteligente com recomendações
  • Monitoramento Passivo (LinkaPulse): Testa a cada 30 min em background
  • Histórico: Salva testes, exporta PDF

Monitoramento Passivo — LinkaPulse v0.6.3

Background speedtest a cada 30 minutos, alertas inteligentes.

Scheduling

  • Framework: WorkManager (Android Jetpack)
  • Período: 30 minutos
  • Constraints: Rede conectada, bateria não baixa
  • Policy: Única execução (KEEP evita duplicatas)

3 Fases de Execução

Fase O que faz Tempo
Collecting Speedtest silencioso + snapshot Wi-Fi 30–60 seg
Thinking Diagnóstico local (engines) 5–10 seg
Analyzing Chamada IA para análise estruturada 3–8 seg

Tipos de Alerta (4)

  • Velocidade Baixa: DL < 25 Mbps → Warn
  • Latência Alta: > 80 ms → Warn
  • Instabilidade: Jitter > 50 ms OU Perda > 2% → Fail
  • Wi-Fi Fraco: RSSI < -70 dBm → Warn

Proteções

  • Cooldown: 2 horas entre alertas iguais
  • Teto: Máx 3 alertas por dia
  • Storage: LocalDB (Room) em tabela AlerteLinkaPulse

Permissões

  • ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE, INTERNET
  • SCHEDULE_EXACT_ALARM (para triggers precisos)
  • POST_NOTIFICATIONS (mostrar alertas)

Testes (14 casos JUnit 4)

Cobertura: transições de fase, cooldown, teto, severidades, IA gateway, rotação mensagens, DB save.

Diagnóstico IA — Orbit

Chat inteligente com recomendações baseadas em métricas de rede.

Fluxo Básico

  1. Usuário faz pergunta no chat Orbit
  2. Sistema coleta contexto (métricas, rede, histórico)
  3. Chamada IA para análise estruturada
  4. Resposta formatada como bolhas de chat
  5. Ações sugeridas (e.g., mudar DNS, reiniciar roteador)

Gateway

URL: https://linka-ai-diagnosis-worker.giammattey-luiz.workers.dev

Cloudflare Worker endpoint — processa diagnóstico sem backend complexo.

Contexto Enviado

  • Velocidade (DL, UL, latência, jitter)
  • Wi-Fi (SSID, força sinal, frequência)
  • Histórico últimos testes (7 dias)
  • Pergunta do usuário + thread chat
