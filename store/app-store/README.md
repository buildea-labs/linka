# App Store Assets

Este diretório contém todos os assets e metadados necessários para a publicação do aplicativo Linka na App Store da Apple.

## Estrutura de Diretórios
- `brand/`: Logos e materiais da marca.
- `metadata/`: Metadados do aplicativo (nome, descrição, palavras-chave, URLs).
- `review/`: Notas e instruções para os revisores da Apple.
- `screenshots/`: 
  - `fontes/`: Arquivos originais ou de design das capturas de tela.
  - `final/pt-BR/iphone/`: Imagens finais geradas para envio ao App Store Connect.
